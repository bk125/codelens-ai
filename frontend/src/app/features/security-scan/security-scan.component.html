Process

How it works

01
Connect GitHub
Authorize read-only access. We request the repo scope so we can read both public and private repositories.
02
Paste Your Repo URL
Enter any GitHub repo URL — public or private. Up to 50 code files are selected automatically. Build artifacts, node_modules, and vendor directories are skipped.
03
AI Scans File by File
Each code file is analyzed by Gemma for exploitable vulnerabilities. A real-time progress bar shows exactly which file is being scanned.
04
Get Your Security Report
A full report with risk score, severity breakdown, CWE IDs, exploit scenarios, and code-level fixes — all grouped and filterable by severity.
🔒
Privacy First
We only read repo contents during the scan. Your code is never stored permanently. GitHub token encrypted at rest with AES-256-GCM.
⚡
Up to 50 Files
Each scan analyzes up to 50 code files. Binary files, build artifacts, and common dependency folders are excluded automatically.
🌐
Public & Private Repos
Both public and private GitHub repositories are supported. You can disconnect GitHub access at any time from this page.
